Analysis, not autopilot

A few perspectives make a better checklist.

The screener combines independent technical and market signals to help organize a watchlist—not to predict what happens next.

01 / MARKET

Read the backdrop

Index direction, global market cues, sector performance and market breadth add context around a potential setup.

02 / SETUPS

Surface candidates

Technical filters look for pre-rally and continuation setups across a configurable universe of Indian equities.

03 / REVIEW

Check the details

Grades reflect independent confirmations. Reports also include levels, risk context and historical signal tracking.

Getting started

From scheduled scan to inbox.

This repository is a Python automation project. The website is its front door; the screener itself runs through its configured workflow.

Configure the project

Set the required environment secrets and optional screener settings for your own setup.

Run the Python screener

Scheduled GitHub Actions workflows fetch market data, evaluate candidates and build a report.

Review the report

Reports are delivered through configured email and optional Telegram notifications. Verify any idea independently.

Risk reminder: Options can lose value rapidly, including the full premium. Market data may be delayed or incomplete. This project is for research and education—not financial advice, trade execution or a promise of results.
